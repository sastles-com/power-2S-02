## 1. mother-ring の変更

### 1.1 部品追加 — 2 点

| Ref | 部品 | LCSC | パッケージ | 面積 |
| --- | --- | --- | --- | --- |
| `U1` (仮) | **PCA9632DP1,118** (I2C 4ch LED ドライバ) | **`C2802665`** | TSSOP-8 (3.0×3.0, リード span 4.9) | 14.7 mm² |
| `C13` (仮) | セラコン 100 nF / 0603 | `C14663` 等 | 0603 | 2.5 mm² |

- **I2C プルアップは追加しない** — AE-BNO055 基板に実装済み ([`docs/09`](09-system-structure.md) §0.5)

### 1.2 推奨配置

実測した空き領域 ([`docs/09`](09-system-structure.md) §0.5):

| 角度範囲 | 幅 | 備考 |
| --- | --- | --- |
| **88°〜121°** | 33° | **`J16`(I2C, 87.7°) と `J13`(3V3, 121.5°) の間 → 推奨** |
| 167°〜208° | 41° | — |
| 216°〜285° | 69° | 最大 |
| 288°〜335° | 47° | — |

**推奨は 88°〜121° の扇形 (半径 24〜38 mm)。** `SDA` / `SCL` / `+3V3` の 3 本が
すぐ隣の `J16` / `J13` にあるため配線が最短になる。40° の扇形で **約 400 mm²** あり、
必要な 17 mm² に対して 20 倍以上の余裕がある。

### 1.3 PCA9632 の結線

| ピン | 名前 | 接続先 | 備考 |
| --- | --- | --- | --- |
| 1 | `LED0` | **`VETO`** → `J7.5` | オープンドレイン。**電源基板側で `V3P3` へ 1 MΩ プルアップ** |
| 2 | `LED1` | **`PWR_OFF`** → `J7.6` | 同上。D-FF の `RD` を引く |
| 3 | `LED2` | 予備 | テストパッド or NC |
| 4 | `LED3` | 予備 | テストパッド or NC |
| 5 | `VSS` | `GND` | — |
| 6 | `SCL` | 既存 `SCL` ネット | ローカル配線 |
| 7 | `SDA` | 既存 `SDA` ネット | ローカル配線 |
| 8 | `VDD` | **`+3V3`** (= AtomS3R 由来) | ⚠️ **`V3P3-ALWAYS` に繋いではならない** (§1.6) |

`C13` (100 nF) は **pin 8 (`VDD`) と pin 5 (`VSS`) の間に、IC の直近に**置く。

⚠️ **I2C アドレスは 0x62 固定** (8 ピン版)。BNO055 (0x28 / 0x29) と衝突しない。

### 1.4 `J7` POWER-02 のピン再定義

| ピン | 現状 | **改版後** | 理由 |
| --- | --- | --- | --- |
| 1 | `GND` | `GND` | 据置 |
| 2 | `CHARGE` | `CHARGE` | 据置 (充電入力 ~1.83 A のため 2 ピン並列) |
| 3 | `CHARGE` | `CHARGE` | 据置 |
| 4 | `GND` | `GND` | 据置 |
| **5** | **`BM`** | **`VETO`** | BM は未使用 (電池と BMS は電源基板へ直接ワイヤ接続) |
| **6** | **`P+`** | **`PWR_OFF`** | P+ も同様に未使用 |

**作業**: `J7.5` → `J14.2` および `J7.6` → `J14.3` の配線を削除し、
`J7.5` を PCA9632 `LED0`、`J7.6` を `LED1` へ接続する。

### 1.5 `J6` POWER-01 のネット再定義

| ピン | 現状 | **改版後** |
| --- | --- | --- |
| 1 / 6 | `GND` | 据置 |
| 2 / 3 | `+5V` | 据置 |
| **4 / 5** | **`5V-ALWAYS`** | **`V3P3-ALWAYS`** (常時オン 3.3 V) |

**理由**: 電源 ON/OFF が **MP1584 の EN 制御**になったため、**電源基板は常時オンの 5 V を作れない**。
一方、常時給電が必要なもの (ホール素子・D-FF・プルアップ) は**すべて 3.3 V** なので、
このピンを **電源基板の HT7333-1 (常時オン 3.3 V / 250 mA) の供給**に振り替える。

**作業**: `5V-ALWAYS` ネットを `V3P3-ALWAYS` にリネーム。`J12` (2 ピン "5V" 引き出し) も
**`V3P3-ALWAYS` の引き出し口**として意味が変わるため、シルクの表記を修正する。

### 1.6 ⚠️⚠️ 最重要: 3.3 V が 2 系統になる — 絶対に接続しない

| ネット | 供給元 | ドメイン | 用途 |
| --- | --- | --- | --- |
| **`+3V3`** (既存) | **M5AtomS3R の 3V3 ピン** (`J4.1`→`J16.6`→`J8.6`) | **ON ドメイン** (AtomS3R と一緒に落ちる) | **PCA9632 の VDD** / I2C の基準 |
| **`V3P3-ALWAYS`** (新規) | **電源基板の HT7333-1** (`J6.4`/`J6.5`) | **常時オン** | 将来の常時給電用 (現時点で負荷なし) |

**この 2 本を接続すると 2 つの故障が起きる:**

1. **常時オン側が AtomS3R の内部レギュレータ出力を逆給電する** → 電源 OFF 中も
   AtomS3R が中途半端に通電し、リーク増加と不定動作を招く
2. **PCA9632 のレジスタが電源 OFF でリセットされなくなる** → 前回の `VETO` 状態が残り、
   **次回起動時にステータス窓が点かない**。PCA9632 は**リセットピンを持たずソフトウェア
   リセットのみ**なので、電源を落とすことが唯一の確実な初期化手段である

**対策 (必須)**: **`+3V3` を `V3P3_SW` にリネーム**し、名前だけで
「常時オンか否か」が判別できるようにする。`V3P3_SW` / `V3P3-ALWAYS` の対比なら取り違えない。

### 1.7 `J14 BATTERY` の扱い — **要判断**

`J7.5`/`J7.6` を転用すると `J14.2 (BM)` / `J14.3 (P+)` の行き先が無くなる。

| 案 | 内容 |
| --- | --- |
| a. `J14` を削除 | 使わないコネクタを残さない。**推奨** |
| b. 未接続端子として残す | 将来の測定用パッドとして残す。ただし「繋がっているように見える」罠になる |

### 1.8 mother-ring 変更チェックリスト

- [ ] PCA9632DP1 (`C2802665`) を 88°〜121° の扇形・半径 24〜38 mm に配置
- [ ] 100 nF (0603) を PCA9632 の `VDD`–`VSS` 直近に配置
- [ ] `SDA` / `SCL` を PCA9632 の pin 7 / pin 6 へローカル配線
- [ ] PCA9632 `VDD` を **`+3V3` (AtomS3R 由来)** へ接続 — **`V3P3-ALWAYS` ではない**
- [ ] `J7.5` → `J14.2` / `J7.6` → `J14.3` の配線を削除
- [ ] `J7.5` = `VETO` / `J7.6` = `PWR_OFF` として PCA9632 `LED0` / `LED1` へ接続
- [ ] `5V-ALWAYS` → **`V3P3-ALWAYS`** にリネーム。`J12` のシルク表記も修正
- [ ] **`+3V3` → `V3P3_SW` にリネーム** (§1.6 の取り違え防止・必須)
- [ ] `J14` を削除するか未接続として残すか決定 (§1.7)
- [ ] `LED2` / `LED3` (予備 2ch) をテストパッドに出すか NC にするか決定
- [ ] ERC / DRC クリーン
- [ ] **`+3V3` (=`V3P3_SW`) と `V3P3-ALWAYS` が短絡していないことを目視 + DRC で確認**

## 2. core-M5atom-FPC の変更 — **物理変更は不要**

<confirmed>
**PCA9632 を mother-ring に置いた結果、core 基板の回路・PCB は一切変更不要。**
必要なのはネット名の整合だけ。
</confirmed>

### 2.1 変更が不要である根拠

| 検討項目 | 結論 |
| --- | --- |
| I2C の引き回し | `SDA`/`SCL` は既に `J16.3`/`J16.4` から ring へ出ている → **追加不要** |
| PCA9632 の電源 | `+3V3` は既に `J16.6` から ring へ出ている → **追加不要** |
| GPIO の追い出し | **GPIO06 (スピーカ) は使わない判断** → `R1` (0 Ω) もそのまま → **変更不要** |
| WS2812 | `GPIO01〜05` → `J17` の既存経路をそのまま使う → **変更不要** |

### 2.2 やること — 名前の整合のみ

- [ ] `+3V3` → **`V3P3_SW`** にリネーム (mother-ring 側 §1.6 と一致させる)
      — **ハーネスで繋がる同一ネットなので、両基板で名前を揃えないと事故要因になる**

### 2.3 参考: 現状のまま残るもの (変更しないことの確認)

| Ref | 内容 | 扱い |
| --- | --- | --- |
| `LS1` SPEAKER (PKLCS1212) | `GPIO06 → R1(0Ω) → C7(0.1µF) → LS1` | **そのまま維持。スピーカ機能は失わない** |
| `R1` 0 Ω | 事実上のジャンパ | **外さない** (GPIO06 は VETO に転用しない) |
| `U1` AE-BNO055 | I2C 0x28/0x29、**プルアップ内蔵** | そのまま。PCA9632 (0x62) と非衝突 |
| `J9` / `J10` I2C (Grove 4p) | SDA/SCL/+5V/GND | そのまま (拡張用) |

## 3. 電源基板 (power-2S-02) 側の対応 — 参考

この改版と対になる電源基板側の作業。詳細は [`docs/06`](06-power-switch.md) / [`docs/08`](08-north-status-window.md)。

- `J7.5` / `J7.6` から `VETO` / `PWR_OFF` を受け、**`V3P3` へ 1 MΩ でプルアップ**
- `J6.4` / `J6.5` へ **常時オン 3.3 V (`V3P3-ALWAYS`) を出力**
- **`CN7` を 6 極**に (`V3P3`/`GND`/`HALL_OUT`/`LED_VCC`/`STAT_PWR_K`/`STAT_CHG_K`)
- **`FF_RD` の POR を 1 MΩ + 10 nF に変更** (τ = 10 ms 不変。100 kΩ だとリーク 33 µA で
  オフ時電流の予算を超える — [`docs/09`](09-system-structure.md) §5.5 破れ ②)
