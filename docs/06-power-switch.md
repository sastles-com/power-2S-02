## 1. 方式変更の経緯 (2026-08-11)

<confirmed>
**旧方式 (モーメンタリボタン + ディスクリートラッチ、130 ms ON / 1.5 s OFF) は廃止した。**
経緯と旧設計の詳細は [§8 付録](#8-付録-廃止した旧方式-ディスクリートラッチ-の記録) に保存してある (再提案禁止のため)。
</confirmed>

### 廃止の決定的理由 — 論理的に両立しなかった

[`docs/08`](08-north-status-window.md) §3 の確定事項:

> **状態表示の駆動元 = フリップフロップの Q (3.3 V)。5V レールではない —
> かざした瞬間に点灯し、MP1584 の soft-start (1.5 ms) すら待たない**

旧方式の確定事項:

> **状態記憶は 5V 出力レール自身**

旧ラッチは 5V が立つことで自己保持するため、**5V が出ていない間は状態を保持する記憶素子が存在しない**
(OFF が唯一の安定状態)。一方 docs/08 は 5V より先に状態が確定していることを要求する。
したがって **5V に依存しない記憶 = 常時オン 3.3 V + FF** が必須で、方式の置換は避けられなかった。

### 置換によって得たもの / 失ったもの

| | 内容 |
| --- | --- |

### ⚠️ RD (Reset) は 3 入力の OR — 他 doc と共用するノード

`FF_RD` は本 doc 単独の持ち物ではない。**3 つのアサート元が同じノードに載る**:

| アサート元 | 管轄 | 形式 |
| --- | --- | --- |
| **パワーオンリセット** (RC) | 本 doc [§4.7](#47-パワーオンリセット-電源投入時-off-の保証) | 電池挿入時に 43.7 ms Low |
| **`PWR_OFF`** (core 基板の PCA9632 ch1) | [`docs/08`](08-north-status-window.md) §4.4b | オープンドレインでシンク |
| **基板上デバッグ SW2** (強制 OFF) | 本 doc [§4.6](#46-基板上デバッグ-sw---sd--rd-に入れる-デバウンス不要) | 機械接点 |

**プルアップは 470 kΩ で統一する** ([§4.7](#47-パワーオンリセット-電源投入時-off-の保証)) — docs/08 §4.4b が
PCA9632 未通電時のリーク削減のために 470 kΩ を要求しているため。

## 3. 却下した方式 (再提案禁止)

| 方式 | 却下理由 |
| --- | --- |
| legacy 踏襲: MAX16054@VOUT + 直列 P-FET | オフ時も MP1584 が動き続ける。オン時は 3 A が P-FET を通り 0.3〜0.5 W の導通損失 |
| MAX16054 + µA 級 LDO + EN 制御 | MAX16054 の VCC 上限 5.5 V で 2S 直給電できない |
| **ディスクリートラッチ (旧候補 A)** | **§1 のとおり docs/08 の「5V を待たずに状態確定」要件と両立しない。** 詳細は [§8](#8-付録-廃止した旧方式-ディスクリートラッチ-の記録) |
| LTC2954-1 (専用 IC) | 単価 $6.73 / 在庫 139 個 / **C グレード 0〜70 °C のみ** (密閉球体 + MP1584 近傍には余裕が薄い) |
| CD4013B + CD40106B | **SOIC-14 が 2 個**で 40×40 片面実装に載らない。出力が VDD (8.4 V) まで振れ EN 用 N-MOS が別途必要 |
| スライドスイッチで EN 直結 | UX が変わる (モーメンタリでない)。球体内での配置制約 |
| ESP32 セルフホールドのみ | ソフト死亡時に切れない |
| 連続動作型ホール IC | mA 級消費でオフ電流予算 50 µA を 100 倍超える ([`docs/08`](08-north-status-window.md) §3) |
| ホールラッチ (bipolar latch) | 磁石を裏返す操作が必要で UX が成立しない ([`docs/08`](08-north-status-window.md) §3) |

### ⚠️ 「単押しトグルはデバウンス必須だから不可」は**ホール素子では成立しない**

旧方式が 130 ms / 1.5 s という UX を選んだ理由は
「モーメンタリ 1 個での単押しトグルは原理的にエッジトリガ = バウンスに晒される」だった。

**ホール IC は磁気ヒステリシス (Bop / Brp) を内蔵しており出力はクリーンな 1 遷移**なので、
機械接点のバウンスが存在しない。**この却下理由は消滅し、D-FF トグルが素直に成立する。**

⚠️ ただし**バウンスとは別に「入力遷移レート」の問題がある** → [§4.3](#43-️-ホール出力を-d-ff-の-clk-に直結できない-規格違反)。
Schmitt バッファは**デバウンスのためではなく遷移レート規格を満たすために**必要。

### 4.2 ネット一覧

| ネット | 内容 |
| --- | --- |
| `PACK_P` | BMS 後の 2S レール (6.0〜8.4 V)。LDO の入力 |

| `FF_Q` | D-FF の Q。**H = 電源 ON / L = OFF**。docs/08 の LED 駆動元でもある |

| `PWR_OFF` | core 基板の PCA9632 ch1 から。オープンドレインで `FF_RD` をシンク |
| `PWR_EN` | MP1584 の EN へ。`FF_Q` と同一ノードだが、ブロック間バス名として維持 |

### 4.3 ⚠️ ホール出力を D-FF の CLK に直結できない (規格違反)

**これが新方式で最も事故りやすい点。**

`74LVC1G74` の推奨動作条件に **入力遷移レート Δt/ΔV ≤ 10 ns/V (VCC 2.7〜5.5 V)** がある
(Nexperia データシート Rev.18 Table 7)。3.3 V 振幅では **立上り 33 ns 以内**が要求値。

| 経路 | 実際の遷移時間 | 判定 |
| --- | --- | --- |
| [`docs/08`](08-north-status-window.md) §4.2 が提案する RC (1 kΩ + 1 nF) | τ = 1 µs → **303 ns/V** | **規格の 30 倍違反** |
| RC 無し・ホール OD + プルアップ 100 kΩ + 北極配線容量 (~10-20 pF) | τ = 1〜2 µs | **やはり違反** |

違反すると **CLK 遷移中に多重クロック / 発振**が起き、**磁石をかざしても ON/OFF がランダムになる**。
CLK は Schmitt 入力ではないので、遅い遷移を受け付ける規格が無い。

<decision>
**`74LVC1G14` (Schmitt インバータ) を CLK の前に必ず入れる。**
Schmitt はヒステリシスを持つので遷移レートの制約が無く、任意に遅い入力を受け付けて
出力は LVC の高速エッジ (数 ns) に整形される。**これで RC フィルタも堂々と入れられる。**
</decision>

### 4.4 インバータが極性問題も同時に解決する

両極検知 (omnipolar) ホール IC は通常 **active-low** (磁石接近で OUT = L)。
`74LVC1G74` は **positive-edge trigger** なので、非反転で繋ぐと**磁石を離した瞬間**にトグルしてしまい、
docs/08 の確定事項「**かざした瞬間**に点灯」に反する。

**インバータを使うと磁石接近が立上りエッジになる** ので、1 部品で遷移レートと極性の両方が解決する。

| ホール素子の出力極性 | 使う素子 | LCSC |
| --- | --- | --- |
| **active-low** (磁石接近で L) ← 想定 | **74LVC1G14** (Schmitt **インバータ**) | `C4469919` |
| active-high (磁石接近で H) | **74LVC1G17** (Schmitt **バッファ**、非反転) | `C3754740` |

⚠️ **両者は同じ SOT-353 (TSSOP-5) フットプリント**なので、
[`docs/08`](08-north-status-window.md) §7 Q1 でホール素子が確定して極性が変わっても、**基板を作り直さずに部品差し替えで対応できる**。

### 4.5 EN 駆動 — D-FF の Q を直結する

<confirmed>
**D-FF の Q を MP1584 の EN へ直結する。N-MOS (旧 Q1) は置かない。**
</confirmed>

| MP1584 EN の性質 | 値 | 直結が成立する根拠 |
| --- | --- | --- |
| **絶対最大定格** | **6 V** | Q の H レベルは V3P3 − 0.1 V = **3.2 V** で余裕 ✓ |
| 立上り閾値 | 1.5 V typ (max 1.65 V) | 3.2 V で確実にイネーブル ✓ |
| 内部プルアップ | 1 µA | CMOS 出力の sink 能力 24 mA @3.0 V に対し無視できる ✓ |
| 0 V まで引く要件 | データシート明記 | CMOS の VOL は 100 µA で 0.10 V max → **確実に引き切る** ✓ |

**旧方式との違い**: 旧 Q1 (2N7002) はオープンドレインだったため
「ON 状態で Q1 のリーク I_DSS が EN のプルアップ 1 µA に迫ると EN が垂れる」問題があり、
**85 °C でのリーク確認が BOM 選定の宿題として残っていた。直結にしたのでこの宿題は消滅する。**

⚠️ `C7` 220 pF は残す。EN は駆動されるノードになったので
[`docs/03`](03-mp1584-module.md) §3.7 要件 4 (高インピーダンスノードのノイズ対策) という当初の根拠は消えたが、
SW ノード近傍を通る可能性があるため保険として維持する (コスト・面積ともに無視できる)。

### 4.6 基板上デバッグ SW — SD / RD に入れる (デバウンス不要)

<confirmed>
**強制 ON = SW1 → SD / 強制 OFF = SW2 → RD。基板上の小型タクト 2 個。外殻に穴は開けない。**
</confirmed>

**なぜ CLK に入れないか**: CLK に入れると**ボタンのバウンスで多重トグルが起きる**。
ホール素子と違い機械接点はバウンスするので、CLK 経路に入れるとデバウンス回路が必要になり、
旧方式で回避したはずの問題が戻ってくる。

**SD / RD は非同期のレベル入力**なので、バウンスしても最終状態は同じ
(何回 Low を繰り返しても Q は 1 / 0 のまま)。**デバウンス回路は不要。**

- `R4` / `R6` = 1 kΩ 直列 — ESD と、SD/RD を直接 GND に落とさないための保護
- ⚠️ **SD と RD を同時に Low にすると出力は不定。** 機械的に別 SW なので通常は起きないが、
  組立時のショートや誤同時押しに注意 (**シルクに注記を入れる**)
- `R3` = 100 kΩ (SD プルアップ) / `R5` = **470 kΩ** (RD プルアップ、§4.7 で理由)
- **磁石を紛失しても、こじ開けて SW1 を押せば電源が入る**のがこの SW の主目的

### 4.7 パワーオンリセット (電源投入時 OFF の保証)

`R5` **470 kΩ** (V3P3 → RD) + `C6` 100 nF (RD → GND)。

- 電池挿入直後は `C6` が放電状態 → **RD = 0 V = リセット有効 → Q = 0 = OFF**
- `C6` が充電され RD が VIH (2.0 V @3.3 V) を超えるとリセット解除:
  `t = −R5·C6 · ln(1 − 2.0/3.3)` = 0.93 τ = **43.7 ms**
- HT7333-1 の立上り (ソフトスタート内蔵、数百 µs〜数 ms) より十分長い ✓
- **旧方式の「R1 一本で保証・競合状態なし」と同等の確実性。** RC 1 組で決まる

**なぜ 470 kΩ か** (100 kΩ ではなく): [`docs/08`](08-north-status-window.md) §4.4b が、
**PCA9632 (core 基板・電源 OFF 中は未通電) の ESD ダイオード経由のリークを抑えるため** 470 kΩ を要求している。
`FF_RD` は `PWR_OFF` と共用ノードなので**値を揃えなければならない** ([§2](#2-確定事項))。

⚠️ **470 kΩ での H レベル余裕の検算**: LVC の入力リークは **±1 µA max**。
最悪 470 kΩ × 1 µA = **0.47 V の降下**で RD = 3.3 − 0.47 = **2.83 V**。
VIH (2.0 V @3.3 V) に対し余裕 0.83 V で成立する ✓
(1 MΩ にすると降下 1.0 V → 2.3 V で余裕 0.3 V となり薄い。[`docs/08`](08-north-status-window.md) §7 V10 の結論と一致)

### ⚠️ max が目標 50 µA を超える

**設計は typ ベースでは成立するが、ワーストケース積み上げでは超過する。** 内訳の支配項は
**MP1584 20 µA + PCA9632 リーク 10 µA + ホール ~8 µA = 38 µA** で、
**この 3 つは本 doc の管轄外**である (docs/03 / docs/08)。

削減の選択肢 (優先順):

1. **ロジック 2 個を Nexperia 品で揃える** (max 4 µA/個)。**TI `SN74LVC1G74` (`C70285`) は ICC max 10 µA** で、
   これを使うと更に +6 µA 悪化する → [§7 Q6](#7-open-questions) の選定要件
2. **PCA9632 のプルアップを更に上げる** — ただし `CLR` は 470 kΩ が上限
   (§4.7 の H レベル余裕の検算より、1 MΩ では余裕 0.3 V で薄い)。`VETO` 側 (1 MΩ) は docs/08 の管轄
3. **ホール素子を低消費品にする** — DRV5032FA (1.6 µA) 系 → docs/08 §7 Q1
4. **目標を「typ ≤50 µA」と定義し直す** — ワーストケース全同時発生は現実的でないため。
   **ユーザー判断が必要** → [§7 Q13](#7-open-questions)

**実測で決める前提**: §9 の検証項目でオフ時電流を実測し、typ 実績で判断する。

### 補足

- プルアップ抵抗 (`R1` 100 kΩ / `R3` 100 kΩ / `R5` 470 kΩ) は OFF 状態で
  **電流の行き先が無いので 0 A** (ホールの OD はオフ、SD/RD は High)。
  **PCA9632 のリークは別物** — 未通電 IC の ESD ダイオードへ流れ込むため電流が立つ
- 旧ラッチは 0.1 µA だった。**本 doc 管轄分の増分は LDO + ロジックの 2.7 µA typ / 12 µA max**

### ⚠️ docs/09 との矛盾 2 件 (ユーザー判断が必要)

[`docs/09`](09-system-structure.md) が本 doc の管轄 (D-FF の SD/RD の使い方) に踏み込んでおり、
**docs/08 の受入基準と矛盾している。**

#### 矛盾 A: 「充電端子を装着すると強制 ON」は docs/08 の受入基準と両立しない

| 出典 | 記述 |
| --- | --- |
| [`docs/09`](09-system-structure.md) §2 | `D-FF: CLK=HALL_OUT / **PRE=充電検出** / CLR=PWR_OFF` |
| [`docs/09`](09-system-structure.md) §5 手順 7 | 充電端子を装着 → D-FF の PRE (SET) → `Q`=H → **強制 ON** |
| [`docs/09`](09-system-structure.md) §5 手順 8 | 電源 OFF のまま充電 → **充電 LED だけ点く** |
| [`docs/08`](08-north-status-window.md) §8 受入基準 | **電源 OFF のまま充電すると充電 LED だけが点く** |

**手順 7 と手順 8 は同時に成立しない。** 充電で強制 ON になるなら「電源 OFF のまま充電」ができない。
さらに **SET が充電中ずっとレベルでアサートされると、充電中は RD で OFF にできなくなる**
(SD と RD の同時 Low = 出力不定、[§4.6](#46-基板上デバッグ-sw---sd--rd-に入れる-デバウンス不要))。

<decision>
**本 doc は「充電検出 → SET」を採用しない。** `FF_SD` は**基板上デバッグ SW1 専用**とする。
理由: docs/08 の受入基準 (電源 OFF のまま充電) が確定事項であり、
充電中の OFF 操作を殺す副作用も大きい。**採用したい場合はエッジ化 (充電開始時のワンショット) が必須。**
</decision>

#### 矛盾 B: ESP32 ソフト電源断の「ペンディング」表記

[`docs/08`](08-north-status-window.md) が 2026-08-11 にペンディングを解除して実装に切り替えた
(PCA9632 ch1 → `PWR_OFF`)。**本 doc §2 は解除済みとして記載を更新した**が、
`CLAUDE.md` §2 と `HANDOFF.md` の「判断済み事項」にも同じ更新が必要
(**この作業で反映済み**)。

## 8. 付録: 廃止した旧方式 (ディスクリートラッチ) の記録

<details><summary>旧 §3.6 確定回路 — 押下 130 ms = ON / 長押し 1.5 s = OFF (2026-08-11 廃止)</summary>

**この方式は §1 の理由で廃止した。再提案禁止。** 以下は判断の記録として残す。

### 旧回路の骨格

- `L` = ラッチノード (H = OFF / L = ON)、`H` = 自己保持ノード、`T` = オフタイマノード、`B` = ボタンノード
- **状態記憶は 5V 出力レール自身**。エッジ検出をどこにも使わないのでデバウンス回路が不要だった
- 電源投入時 OFF は `R1` 2.2 MΩ で `L` を `P+` へプルアップして保証 (競合状態なし)
- しきい値を NPN の Vbe = 0.6 V 基準にしてタイマばらつきを ±20% に抑えた
  (MOSFET Vth 基準なら 2.5 倍振れる)

### 旧 BOM (SW1 除き 21 点)

| --- | --- | --- | --- |

### 旧設計で判明していた要注意点 (新方式では全て消滅)

1. **Q5 / Q6 が無いとターンオフが中断する** — `L` 上昇で Q5 が `T` を短絡し Q3 が OFF に戻るため、
   軽負荷で `V5` の崩壊が遅いと Q2 が復活する。負荷依存の設計を避けるため Q5/Q6 で構造的に排除した
2. **OFF 直後 20 秒間再 ON できない問題** — C2 (4.7 µF) を R4 (4.7 MΩ) だけで放電すると τ = 22 s。
   Q5 が OFF 中に `T` を短絡してタイマをリセットすることで解決した
3. **`T` ノードのリーク管理** — ON 中フローティングになる高インピーダンスノード。
   リークで 0.6 V まで上がると勝手に OFF する。R4 4.7 MΩ で排出 (余裕 2.5 倍)
4. **Q1 のオフリークは 1 µA 未満必須** — MP1584 の EN プルアップが 1 µA しかないため。
   **新方式は Q を直結するのでこの制約が消えた** (§4.5)

### 旧方式の回路図実装 (2026-08-11 に作図完了 → 廃棄)

## 9. 試作での検証項目

§4 の回路はデータシートのリファレンス回路ではなく自前設計なので、**実測での確認を前提とする**。

- [ ] **磁石をかざして 1 回だけトグルすること** — 多重トグルが起きないか (§6 申し送り 3)
- [ ] **磁石を Bop 付近でゆっくり止めた場合の挙動** — 間欠動作の周期で複数トグルしないか
- [ ] **かざした瞬間に北極が点灯すること** — MP1584 の soft-start を待っていないか ([`docs/08`](08-north-status-window.md) §8)
- [ ] **CLK 波形の実測** — Schmitt 出力の立上りが 33 ns 以内であること (§4.3)
- [ ] **電池挿入時に OFF であること** (複数回、電池電圧 6.0 / 7.4 / 8.4 V で)
- [ ] **BMS カットオフ → 復帰時に OFF であること** (過放電の再突入ループ防止)
- [ ] **基板上 SW1 / SW2 が強制 ON / OFF として動くこと**。バウンスで誤動作しないこと
- [ ] **`PWR_OFF` (core 基板の PCA9632 ch1) で電源が切れること**、かつ**再投入ループが起きないこと**
- [ ] **`FF_RD` の H レベルを 470 kΩ プルアップで実測** — VIH 2.0 V に対する余裕 (§4.7 の検算は 2.83 V)
- [ ] **PCA9632 未通電時のリーク実測** — 設計見込み ~10 µA ([`docs/08`](08-north-status-window.md) §4.4b)。§5 の max 超過の主要因
- [ ] **オフ時電流の実測** — 設計値 **27〜29 µA typ** (§5)。max 超過の判断 (§7 Q13) はこの実測で決める
- [ ] **HT7333-1 の 3.3 V が 2S 全域 (6.0〜8.4 V) で規定内であること**。
      ⚠️ 推奨 VIN は VOUT+2 = 5.3 V 以上なので、BMS カットオフ間際で規格外になる瞬間がある
- [ ] **85 °C での 3.3 V とオフ電流** — HT7333-1 の動作温度上限ちょうど (Q10)
- [ ] 充電中に OFF を維持できること / 充電中に北極の充電 LED が点くこと
- [ ] **南極の充電マグネットを着脱してもホール素子が誤反応しないこと** ([`docs/08`](08-north-status-window.md) §8)
