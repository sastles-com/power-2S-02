## 1. 確定事項 (2026-08-10)

<confirmed>
- **方式: ディスクリートラッチ + MP1584 の EN 制御** (MAX16054 は使わない)。
  **回路・定数は 2026-08-11 に確定 → [§3.6](#36-確定回路-候補-a-2026-08-11)**
- **UX (2026-08-11 確定): 押下 130 ms 以上で ON / 押下 1.5 s 以上で OFF。**
  単押しトグルは原理的にエッジトリガ (= デバウンス必須) を要求するため採らない (§3.5)
  - 2S 電圧 (6.0〜8.4 V) で直接動作するラッチを組み、降圧 IC の EN を駆動する
  - **直列パス FET は置かない** — 負荷電流 (最大 3 A) は素子を通らない
  - オフ時は降圧 IC 自体が停止するので、コンバータの静止電流も消える
- **付帯要件 (実装する)**:
  - **電源状態 LED** — オン / 充電中を目視で判別できる表示。
    ✅ **「充電中」表示のブロッカーは解消** (2026-08-10) — IP2326 に **LED 専用出力ピン (pin 6)** があり、
    **充電中 = 点灯 / 満充電 = 消灯 / 異常 = 点滅**を IC 側が自動でやる ([`docs/02`](02-ip2326-module.md) §3.5)。
    → **LED は 2 個構成**: 充電表示 (IP2326 の LED ピン + 100 Ω) と 電源オン表示 (本ラッチ回路側) を分ける
- **付帯要件 (ペンディング)**:
  - **ESP32 からのソフト電源断** — 2026-08-10 に**一旦ペンディング**。
    ただし将来追加できるよう **ラッチのオフ側ノードにパッド (テストポイント) を 1 個予約**しておく
    (基板再製作なしで後から実装できるようにする。回路は未実装)
- **付帯要件 (実装しない)**:
  - 強制オフ (legacy の CLR 相当) 専用端子は設けない
  - ESP32 への電源状態通知 (PWR_STATE 出力) は今回のスコープ外
</confirmed>

## 1.1 EN 駆動仕様 (2026-08-10 確定 — MP1584 データシート照合の結果)

<confirmed>
**ラッチは EN を「オープンドレインで GND へ引き下げるだけ」。プルアップも分圧も付けない。**
根拠と数値は [`docs/03`](03-mp1584-module.md) §3.7。
</confirmed>

| MP1584 EN の性質 | 値 | ラッチ設計への影響 |
| --- | --- | --- |
| **floating = イネーブル** | 内部 1 µA プルアップで約 3.0 V まで上がる | **ON 状態はラッチが「何もしない」= 開放。プルアップ回路は不要** |
| 引き下げに必要な能力 | **1 µA** | 小信号 N-MOS / NPN 1 石で足りる |
| **絶対最大定格** | **6 V** | **⚠️ EN を 2S レール (6.0〜8.4 V) に直結・接続してはならない**。オープンドレイン構成なら EN は 2S に触れないので自動的に安全 |
| 立上り閾値 | 1.5 V typ (min 1.35 / max 1.65) | — |
| 立下り閾値 | 1.2 V (precision)、ヒステリシス 300 mV | — |
| シャットダウン時消費 | **12 µA typ / 20 µA max** | §5 Q1 のオフ電流目標を支配する (下記) |

### 設計要件 4 件 (docs/03 §3.7 からの申し送り)

1. **プルアップ/分圧を付けない。** 付けると 6 V 絶対最大の管理が必要になり、常時電流も流れる
2. ⚠️ **電池を挿した直後のデフォルトは「電源 ON」になる** — EN が floating = イネーブルのため。
   これを避けるには **ラッチの電源投入時状態を「EN を引き下げる」側に確定させる回路**
   (RC によるパワーオンリセット等) が必要。**2 石ソフトラッチの素朴な構成では初期状態が不定になりうる**
   → §5 Q2 の回路選定で必ず考慮する
3. **OFF 時は EN を GND まで確実に引き切る。** データシートに「EN が 0 V より高く立上り閾値より低い場合、
   シャットダウンではあるが消費電流がやや増える」と明記
4. **EN は開放時 1 µA という高インピーダンスノード** → SW ノードから離して配線し、
   ノイズ対策に **EN–GND 間へ 220 pF** 程度を入れる (立上り遅延 0.33 ms、ソフトスタート 1.5 ms に対し無視できる)

## 2. 却下した方式とその理由 (再提案禁止)

| 方式 | 却下理由 |
| --- | --- |
| legacy 踏襲: MAX16054@VOUT + 直列 P-FET | オフ時も MP1584 が動き続ける (常時消費)。オン時は 3 A が P-FET を通り 0.3〜0.5 W の導通損失 |
| MAX16054 + µA 級 LDO + EN 制御 | MAX16054 の VCC 上限は 5.5 V で 2S 直給電できず、LDO 追加が必要。ディスクリートラッチなら LDO 不要で同等以上 |
| ⚠️ **注記 (2026-08-10)**: 上の却下理由は **「VCC 5.5 V で 2S 直結できない」という MAX16054 固有の事情**である。**2.7〜26.4 V で動く専用 IC (LTC2954) はこの理由に当てはまらない** → §3.5 候補 B として再評価対象にした (判断済み事項の蒸し返しではなく、新情報による) | |
| スライドスイッチで EN 直結 | UX が変わる (モーメンタリでない)。球体内での配置制約 |
| ESP32 セルフホールドのみ | 電源基板が別基板のソフトに依存。ソフト死亡時に切れない |

## 3. 回路要件

| 項目 | 要求 |
| --- | --- |
| 電源電圧 | **2S 直接 (6.0〜8.4 V)**。降圧・LDO を介さない |
| 操作 | モーメンタリ押しボタン 1 個。**押下 130 ms = ON / 長押し 1.5 s = OFF** (2026-08-11 確定、§3.6) |
| オフ時消費電流 | ~~≤ 10 µA~~ → **≤ 50 µA に改定** (2026-08-10)。**MP1584 のシャットダウン電流 12 µA typ / 20 µA max が下限を決めるので ≤10 µA は物理的に不可能** ([`docs/03`](03-mp1584-module.md) §3.9)。**実績見込み: ラッチ ~0.1 µA / システム合計 13 µA typ** (§3.6.7) |
| 出力 | 降圧 IC の **EN** を**オープンドレインで引き下げる**だけ (§1.1)。分圧・プルアップは付けない |
| ESP32 入力 | **ペンディング** — 回路は実装しないが、ラッチのオフ側ノードにパッドを 1 個予約。将来実装時は ESP32 が 3.3 V 系のため**レベル整合が必要** (2S 系への直結不可、小信号 N-MOS 等を介す) |
| LED | オン表示 + 充電中表示。輝度は最小限 (常時点灯のため消費電流を抑える) |
| デバウンス | **方式次第** (§3.5)。候補 A はエッジ検出を使わないので不要、候補 B は内蔵、候補 C は外付け Schmitt が必須 |

## 3.5 実装方式の候補比較 → **候補 A で確定 (2026-08-11 ユーザー判断)**

### 前提: 「モーメンタリ 1 個で単押しトグル」は原理的にエッジトリガを要求する

単押しでトグルするには **T フリップフロップ相当のエッジ検出**が必要で、
これはボタンのバウンスに直接晒される。回路的には次のどれかになる:

- 専用の押しボタン ON/OFF コントローラ IC (デバウンス内蔵)
- ロジック FF + Schmitt デバウンサ
- ディスクリートの双安定 + 容量結合ステアリング

3 番目は**部品ばらつきに敏感**で、かつ**データシートのリファレンス回路が存在しない**
(本プロジェクトの「データシート標準回路 + 自前計算」原則に反する)。
そこで **UX を変えれば真ディスクリートで確実に作れる**方式 (下の A) を含めて 3 案を比較した。

### ✅ 候補 A: 真ディスクリート / **押下 130 ms = ON、長押し 1.5 s = OFF** ← **採用**

**確定回路と全定数は [§3.6](#36-確定回路-候補-a-2026-08-11) に記載。以下は選定時の評価。**


エッジ検出をどこにも使わないので、**構造的にバウンス耐性がある**。

| 動作 | 仕組み |
| --- | --- |
| **電源投入時 = OFF** | ラッチノード `L` を **2.2 MΩ で 2S へプルアップ** → `L`=H → EN を GND に引く。**抵抗 1 本で保証され、競合状態が存在しない** |
| **押下で ON** | ボタンが `L` を GND へ引く → EN 開放 → MP1584 起動 → **5V が立つ** → 保持タイマ経由で自己保持に入る |
| **長押しで OFF** | ボタン押下を P-MOS で反転して RC タイマを充電 → しきい値到達で保持ノードを潰す → `L` が復帰 → EN=L → 5V 崩壊 → OFF |

- **状態記憶は 5V レール自身**なので曖昧さがない
- 主要部品が **Basic** (2N7002 = C8545 在庫 145 万 / MMBT3904 = C20526 在庫 70 万) で**約 $0.3**
- **オフ電流はラッチ側で実質ゼロ** (§3.6.7) → 3 案中で最小
- 面積: すべて SOT-23 / SOD-123FL / 0603 で 40×40 に載る
- **確定仕様「ディスクリートラッチ」を維持できる**
- ✗ 欠点: **UX が単押しトグルでない** (Bluetooth スピーカー等でよくある操作系)

> ⚠️ 選定時 (2026-08-10) の見積りは「部品 11 点 / オフ電流 3.8 µA / タップ 30 ms」だったが、
> §3.6 で ESD 対策・タイマリセット・誤 ON 防止を織り込んだ結果
> **21 点 / オフ電流 ~0.1 µA / 押下 130 ms** に更新されている。**確定値は §3.6 を見ること。**

### 候補 B: **LTC2954-1** 専用 IC / 単押しトグル

要件を**すべてネイティブに満たす**。データシート実測値:

| 項目 | 値 | 評価 |
| --- | --- | --- |
| 電源範囲 | **2.7〜26.4 V** | **2S 直結可 → MAX16054 を却下した理由 (VCC 5.5 V) が当てはまらない** |
| 消費電流 | **6 µA typ / 12 µA max** | ○ |
| **EN 出力** | オープンドレイン、**リーク ±0.1 µA max** (`-1` = Low Leakage 版) | **MP1584 の 1 µA プルアップと整合。`-1` が必須** |
| **電源投入時** | データシート明記: 「電源投入時に出力ピンを初期化し、EN に繋がる DC/DC は OFF になる」 | **§1.1 要件 2 が無料で解決** |
| デバウンス | 内蔵。ON は 32 ms 押下、OFF は 64 ms 押下 (ONT/PDT を開放時) | **通常の押下 (~150 ms) で単押しトグルになる** |
| 再トグル防止 | EN Lock Out 256 ms | ○ |
| **KILL 入力** | 0.6 V 閾値。Low で EN 解放 | **予約していた「ESP32 ソフト電源断」パッドの定義済みインターフェース** |
| INT 出力 | デバウンス済みボタン状態 | 将来 ESP32 通知に使える |
| ボタン入力 | 内部 100 kΩ プルアップ + **±10 kV ESD HBM** | 球体外殻からの引き出しに強い |
| パッケージ | TSOT-23-8 | ○ |

- ⚠️ **KILL を 512 ms 以内に High にしないと自動で OFF に戻る** (µP 参加を前提にした設計)。
  µP なし運用では **5V 出力から 100 kΩ でプルアップ**する必要がある。
  これは同時に **5V レールモニタ**として働き (5V 喪失で自動電源断)、
  ESP32 側はオープンドレインで KILL を引くだけでよい → 副作用として設計が綺麗になる
- ⚠️ **600 ms 超の長押しでは「ON → 待機 → OFF」と連続動作する**癖がある (ブランキング後もボタンが押されているため)
- ✗ 欠点 3 点:
  - **単価 $6.73 (1+) / $5.89 (10+)** — 基板 1 枚のコストに対して無視できない
  - **在庫 139 個のみ** (`LTC2954CTS8-1#TRPBF` = **C683782**)。`-1` の I グレード品は在庫 0
  - **C グレード = 0〜70 °C しかない**。密閉球体内で MP1584 (ΔT 60 °C) の近傍という環境では余裕が薄い
  - 判断済み事項「ディスクリートラッチ」の変更が必要

### 候補 C: CD4013B (D-FF) + CD40106B (Schmitt) / 単押しトグル

- 両方 **VDD 3〜18 V** で 2S 直結可、静止電流は各数 µA
- 在庫豊富・安価: **CD4013BM96 = C13527 (SOIC-14, 14,494)** / **CD40106BM96 = C38184 (SOIC-14, 16,060)**
- D = /Q でトグル、CD4013 の Reset に RC を付けて**電源投入時 Q=0 (OFF) を保証**
- CD4013 の CLK は Schmitt ではないので **CD40106 でのデバウンスが必須** (直結すると多重クロックで誤動作)
- ✗ 欠点: **SOIC-14 が 2 個**。40×40 / 片面実装で充電段 + 降圧段と同居させるには面積が厳しい
- 出力は VDD (8.4 V) まで振れるので、**EN 駆動用の N-MOS は結局必要** (EN 絶対最大 6 V)

### 3.6.1 ネットと構成

| ネット | 内容 |
| --- | --- |
| `P+` | BMS 後の 2S レール (6.0〜8.4 V)。ラッチの電源 |
| `V5` | MP1584 の 5V 出力。**状態フィードバックを兼ねる** |
| `PWR_EN` | MP1584 の EN ピンへ ([`docs/03`](03-mp1584-module.md) §3.7) |
| `L` | ラッチノード。**H = OFF / L = ON** |
| `H` | 自己保持ノード (Q2 のベース)。Q2 の B-E で **~0.7 V にクランプされる** |
| `T` | オフタイマノード (Q3 のベース) |
| `B` | ボタンノード。押下で GND |

```
       GND (Q1.source)

            ├── Q4.source (P-MOS, gate=B 経由 R7)
            │        │
            │       Q4.drain ── R3 2.4M ──┬── T ──┬── Q3.base
            │                             │        └── Q5.drain (OFF 中に T をリセット)

            │                             │
            │                            GND
            │
            └── R8 1.5k ── D2 (LED 赤) ── GND      電源 ON 表示
```

| SW1 | タクト SW | 未定 | — | モーメンタリ。基板外 → コネクタ経由 (§5 Q3) |

⚠️ **D1 の選定に注意**: 最も流通している **`ESD9B5.0` (5 V 品) は使えない**。
`B` は解放時に `P+` = 最大 8.4 V が載るため、5 V standoff では常時導通してしまう。
**standoff ≥ 12 V** が必須。SMF12A (12 V standoff / 破壊 13.3〜14.7 V / 在庫 80,360) を選定した。

### 3.6.3 動作表

| 状態 | 操作 | 結果 |
| --- | --- | --- |
| **電池挿入** | — | R1 が `L`=`P+` → Q1 ON → EN=L → **OFF**。抵抗 1 本で決まるので**競合状態が存在しない** |
| OFF | 130 ms 未満のタップ | 自己保持が確立せず OFF に戻る (LED が一瞬光るだけ) |
| OFF | **130 ms 以上の押下** | **ON** (Q2 が自己保持に入る) |
| ON | 1.5 s 未満の押下 | **何も起きない** (no-op) |
| ON | **1.5 s 以上押して離す** | **OFF** |
| OFF | 1.5 s 以上押し続ける | ON → タイマ満了 → 離すと OFF (差し引きゼロ)。**仕様として「長押しはどの状態からでも OFF」** |
| OFF 中に充電 | — | IP2326 は独立して充電。`V5`=0 なので OFF を維持 ✓ |
| BMS カットオフ → 自動復帰 | — | ラッチも一緒に電源断 → **復帰時は必ず OFF**。過放電の再突入ループを防ぐ ✓ |

### 3.6.4 タイミング計算

しきい値を **NPN の Vbe = 0.6 V** にしたので、MOSFET の Vth (2N7002 で 1.0〜2.5 V の 2.5 倍ばらつき) に
依存せず、**ばらつきが ±20% 程度に収まる**。

| 項目 | 式 | 設計値 | ばらつき (Vbe 0.55〜0.65 V, C ±10%) |
| --- | --- | --- | --- |
| **ON 押下時間** | `t = −R2·C1 · ln(1 − 0.6/5)` = 0.128 τ | **128 ms** | **103〜153 ms** |
| **OFF 長押し時間** | R3∥R4 = 1.59 MΩ、`T` 到達点 = 5×4.7/7.1 = 3.31 V<br>`t = −1.59M·C2 · ln(1 − 0.6/3.31)` | **1.49 s** | **1.2〜1.8 s** |
| ターンオフ時の `L` 立上り | R1 · C3 = 22 ms、Q1 の Vth 到達 | 約 8 ms | — |
| `V5` 崩壊 | 出力 44 µF ÷ 静止負荷 0.7 A | 315 µs | — |

**ON 押下 130 ms は意図的**: 当初案 (20 ms) では鞄の中などで軽く触れただけで ON になり得る。
C1 を 1 µF にするだけ (**部品追加ゼロ**) で「意図的なタップ」を要求できる。
OFF の 1.5 s との比は 10 倍以上あり、誤認しない。

### 3.6.5 設計上の要注意点 4 件

#### ① Q5 / Q6 が無いとターンオフが中断する (競合状態)

ターンオフの順序:

1. `T` が 0.6 V 到達 → Q3 ON → `H` を GND へ
2. Q2 OFF → `L` が R1 経由で上昇 (τ = 22 ms)
3. `L` > Q1 の Vth (約 8 ms) → Q1 ON → EN=L → MP1584 停止 → `V5` 崩壊
4. **同時に Q5 / Q6 が ON → `T` と `H` を GND に固定** → Q3 / Q2 が確実に OFF → ラッチ完了

**Q6 が無い場合**: 手順 2 で `L` が上がると Q5 が `T` を短絡し Q3 が OFF に戻るため、
`H` が `V5` から再充電され得る。負荷が軽く `V5` の崩壊が 128 ms より遅いと
**Q2 が復活してターンオフが中断する**。本設計の負荷 (WS2812 静止 0.6〜0.8 A) では
`V5` は 315 µs で消えるので実害は出ないが、**「負荷の重さに動作が依存する」設計は避ける**べきなので
Q5/Q6 を入れて構造的に排除した。

#### ② OFF 直後に再 ON できない問題を Q5 で解決している

C2 (4.7 µF) を R4 (4.7 MΩ) だけで放電すると τ = 22 s かかり、
その間 `T` が高いまま = Q3 が `H` を潰し続けるため **20 秒ほど再 ON できない**。
Q5 が `L`=H (= OFF 状態) の間 `T` を GND に短絡するので、**OFF になった瞬間にタイマがリセットされる**。
同じ理由で Q6 が C1 をリセットし、次回の ON も必ず 130 ms を要求する。

#### ③ `T` ノードのリーク管理

`T` は ON 中フローティングになりうる高インピーダンスノード。リークで 0.6 V まで上がると**勝手に OFF する**。
R4 (4.7 MΩ) を GND へ入れてリークを排出する。
- 基板表面リーク 50 nA を仮定すると 50 nA × 4.7 MΩ = **0.235 V** (Vbe の 39%) → 余裕 2.5 倍
- R4 を大きくすると余裕が減り、小さくすると `T` の到達点が下がってタイマが伸びる。**4.7 MΩ が妥協点**
- 試作で**数時間放置して勝手に OFF しないこと**を確認する (§6)

#### ④ Q1 のオフリークは 1 µA 未満でなければならない

MP1584 の EN プルアップは **1 µA しかない** ([`docs/03`](03-mp1584-module.md) §3.7)。
ON 状態 (Q1 オフ) で Q1 のリーク I_DSS がこれに近づくと EN 電圧が垂れて誤シャットダウンする。

- 2N7002 の I_DSS 規格は 1 µA max (VDS 60 V / 25 °C)。実使用は **VDS ≈ 3 V** なので桁で下がるが、
  **球体内 85 °C でのリークを BOM 選定時に確認する**。目標 **< 100 nA** (余裕 10 倍)
- 参考: 候補 B (LTC2954-1) は EN リークを **±0.1 µA max** で規格保証している。
  ディスクリート採用のトレードオフはここに出る

### 3.6.6 ESP32 ソフト電源断パッド (回路未実装・パッドのみ)

- **`H` ノードにパッドを予約する。** `H` を GND に引けば即 OFF になる
- **`H` は Q2 の B-E 接合で ~0.7 V にクランプされる** ので、**ESP32 の 3.3 V GPIO で安全に引ける**
  (5 V トレラントである必要がない)。2S 系ノードへの直結問題は起きない
- 実装時は **直列 1 kΩ** を入れ、オープンドレインまたは GPIO の Low 出力で引く
- 確定仕様どおり**回路は実装しない**。パッド 1 個のみ

### 3.6.7 オフ時消費電流 — **ラッチ側は実質ゼロ**

OFF 状態では `L` = `P+` で**何も電流を引かない** (Q1/Q5/Q6 はゲート、消費なし)。
R1 / R5 は電流の行き先が無いので **0 A**。`V5` = 0 なので R2 / R3 / R8 も 0 A。

| 要因 | 電流 |
| --- | --- |
| **ラッチ回路 (本設計)** | **リークのみ ≈ 0.1 µA** |
| MP1584 シャットダウン | 12 µA typ / 20 µA max |
| IP2326 スタンバイ | 0.7 µA typ / 1 µA max |
| **システム合計** | **約 13 µA typ / 21 µA max** |

→ 目標 **≤50 µA を大きく下回る**。2000 mAh に対し typ で **17 年**相当
(実際は LiPo の自己放電 ~82 µA 相当が支配的)。
